С чего начать
  1. Добавьте ключ облачной модели — поставщик определится сам — и отметьте модели.
  2. По желанию добавьте ключ RuCaptcha: люди решат то, что не смогли модели.
  3. Подключите свою программу: адрес и ключ доступа — в разделе «Подключение».

Порядок решения

Капча идёт сверху вниз: следующий слой включается, если предыдущий не справился, не уверен или не умеет такой вид.

Облачные модели

Вставьте ключ — поставщик и список моделей определятся сами. Ключи хранятся в Связке ключей macOS.

Люди

Решают всё, включая reCAPTCHA, hCaptcha и Turnstile. Платно — лимит в разделе «Лимиты».

Пополнить

Лимиты

0 — без лимита. Когда лимит исчерпан, слой пропускается до конца дня, и приходит уведомление.

Подключение программ

Решатель понимает API 2Captcha и RuCaptcha. В своей программе поменяйте адрес сервиса на этот, а ключ API — на ключ доступа.
