# Я не робот

[English](README.md) · **Русский**

**Решатель капч для macOS, который сначала пробует бесплатное.** Замена API 2Captcha и RuCaptcha: капчу сначала решает своя модель, потом бесплатная облачная, потом невидимый браузер, а люди за деньги — только если не справился никто. Есть программа в строке меню и MCP-сервер для ИИ-агентов.

![Я не робот: окно и панель в строке меню, демонстрационные цифры](docs/images/hero.png)

## Зачем

- **Бесплатно по умолчанию.** С бесплатным ключом Gemini API большинство капч до платной ступени не доходит.
- **Без правки кода.** Любая программа, которая умеет API 2Captcha или RuCaptcha, работает после смены одного адреса.
- **Лестница, а не одна ставка.** Своя модель → облачная → запасная облачная → браузер → люди. Ступень, которая не уверена, ошиблась или молчит, передаёт капчу следующей.
- **Учится на ошибках.** Отметили ответ неверным — ступень больше не решает эту картинку; ступень, которая часто ошибается на каком-то виде капч, для него пропускается; жалоба на ответ людей уходит сервису, и он возвращает деньги.
- **Всё на виду.** Журнал каждой капчи с картинкой, ответом и путём по ступеням, лимиты денег на день, сравнение моделей.
- **Для агентов.** MCP-сервер: Claude, Cursor и другие агенты решают капчи через программу.

## Быстрый старт

1. Скачайте `ImNotARobot.dmg` из [Releases](https://github.com/zigansh1n/imnotarobot/releases) и перенесите программу в «Программы». В Finder она называется «Я не робот». Подписи Apple пока нет: если macOS не даст открыть, нажмите «Всё равно открыть» в Системных настройках → Конфиденциальность и безопасность.
2. Возьмите бесплатный ключ Gemini на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и вставьте его в «Ключи и модели». Нужные модели включатся сами.
3. В своей программе поменяйте адрес сервиса капч на `http://127.0.0.1:8765`, а ключ — на ключ доступа из раздела «Подключение».

По желанию добавьте ключ RuCaptcha или 2Captcha — последней, платной ступенью.

## Как это работает

| Ступень | Решает | Цена | Время |
|---|---|---|---|
| 1. Своя модель (ddddocr, сравнение кусочков) | текст, слайдеры | бесплатно | доли секунды |
| 2. Облачная модель (по умолчанию Gemini Flash) | текст, сетки картинок, клики | бесплатная квота | 3–8 с |
| 3. Запасная облачная (Gemini с раздумьями) | то, в чём вторая не уверена | бесплатная квота | 10–50 с |
| 4. Браузер (невидимый Chrome) | reCAPTCHA v2/v3, hCaptcha, Turnstile | бесплатно | от 3 с до 2 мин |
| 5. RuCaptcha / 2Captcha | всё | платно | 10–60 с |

## Замеры

На нашем наборе и официальных демо-страницах, октябрь 2026. Выборки маленькие; часть с галочками повторите сами: `python -m imnotarobot.demo_bench --runs 10`.

| Капча | Результат |
|---|---|
| Текст, сетки картинок (облачная модель) | 100% |
| Клики на настоящих капчах (облачная модель) | 69–72% из 39 |
| reCAPTCHA v2 на демо Google (браузер) | Google принял 2 из 3, медиана 118 с |
| reCAPTCHA v3, тестовый ключ Turnstile (браузер) | 5 из 5, 3–4 с |
| hCaptcha на демо (браузер) | 5 из 5, медиана 82 с |

## Сервер (Docker)

То же API и MCP на Linux, без окна:

```bash
docker build -t imnotarobot .
docker run -p 8765:8765 -e GEMINI_API_KEY=... -e CLIENT_KEY=ваш-ключ-доступа -v imnotarobot:/data imnotarobot
```

`HUMAN_API_KEY` (и `HUMAN_PROVIDER=2captcha`, если нужно) добавляет платную последнюю ступень. Ключи лежат в `/data/secrets.json`, читать его может только сервер.

## Сборка из исходников

```bash
uv venv -p 3.12 .venv && uv pip install -p .venv/bin/python -e ".[test]" pyinstaller
.venv/bin/python -m pytest -q
packaging/build.sh          # собирает ImNotARobot.app в ~/Applications
.venv/bin/python -m imnotarobot --port 8765   # только сервер, без окна
```

Программа говорит на языке системы: русском или английском. Настройки, журнал и ключи лежат в `~/Library/Application Support/captcha-stack` и Связке ключей (служба «Captcha Stack») — у них осталось первое имя проекта, чтобы при переименовании ничего не потерялось.
